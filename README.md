# Cloud-portfolio-server
My portfolio currently runs on Vercel, which handles everything for me. In this project I'm moving it onto my own Linux server in the cloud so that I can learn how hosting actually works
goal: A server that I setup on my own from scratch that upadtes my site everytime I push to GitHub

## The plan

- [ ] Create a Linux VM in the cloud
- [ ] Connect to it securely with SSH
- [ ] Learn the Linux basics (users, permissions, firewall)
- [ ] Install Nginx and serve a page
- [ ] Deploy my portfolio by hand
- [ ] Add a domain and HTTPS
- [ ] Auto-deploy with GitHub Actions

## Status
In progress....Learning how to setup a Linux VM, Linux basics and other related fundamentals
